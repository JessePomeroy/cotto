# App screenshots

These PNGs are renders of the actual native SwiftUI views with synthetic example data, generated by `Tests/SottoTests/ViewSnapshotTests.swift`. They are not photographs of a live recording; example transcripts and timings are illustrative. No personal history, audio, clipboard, or screen content is used.

Regenerate the native views with `./scripts/native-ui-snapshots.sh /absolute/output/directory`:

| Published file | Native render |
| --- | --- |
| `dictation.png` | `native-preview-dashboard-ready-dark.png` |
| `models.png` | `native-preview-models-complete-dark.png` |
| `menu.png` | `native-preview-menu-ready-dark.png` |
| `listening.png` | `native-preview-hud-recording-rest-dark.png` |

Offscreen native rendering does not include system window chrome or fully reproduce WindowServer glass/vibrancy. The running app uses macOS materials.
